# iPad 可编辑文字、形状与图层效果

本功能在曲线/色阶调整层之后接入。文字、形状和效果均在本机工作，不依赖 Windows。

## 文字与形状

顶栏“文字与形状”菜单提供新建文字、新建形状和重新编辑入口；选中对应层后也可在图层面板编辑。新层插入所选普通层完整剪贴堆栈上方，选中组时加入组内。完成一次事务；取消、空白新文字、未改变的重编不清空重做。

文字支持正文、字体、字号、RGB 颜色、左/中/右对齐、字距、行距和段落框换行。通过系统字体选择器选择本机字体。工程保存 PostScript 字体名和原 PNG；缺字体时打开工程仍使用原 PNG，进入编辑面板会明确提示，修改后需选择可用字体才可完成。不会打开工程就自动重排旧文字。

本轮正文编辑为整段输入。既有局部颜色/字体参数可以读取、渲染和原样保存；修改正文时统一局部样式，选择统一字体/颜色时清除相应局部覆盖，面板有说明。UTF-16 范围、次序与重叠严格验证；不支持未知富文本字段。

形状支持矩形、椭圆、直线、圆角与平滑圆角、颜色和线宽。完成后使用既有自由变换移动、缩放和旋转。圆角保持文稿像素尺寸；缩放预览和原子提交重新生成形状缓存，避免把圆角直接放大。直线保存端点在矩形内的比例，横竖方向可再次修改。

## 图层效果

“文字与形状”菜单中的“图层效果…”可用于普通像素、文字和形状层。支持描边（内/外）、投影、颜色叠加、内阴影、外发光与内发光，均可修改颜色、不透明度、适用的大小/距离/角度/模糊参数，单独关闭和移除。六项参数使用官方字段独立存储，源 PNG 不被改写；重开工程可继续编辑。组与调整层不能携带效果，未知效果或嵌套字段严格拒绝。

Own mask 先作用于内容一次，再从该覆盖生成描边/投影等效果；绘制成品时不重复剪蒙版。内效果保留原覆盖。外效果按扩边表面绘制，普通几何仍表示原内容矩形。剪贴子层使用带效果、蒙版与不透明度的基底成品 alpha；合并边界包括效果，画布、预览、正式导出和 AI 输入共享相同合成路径。

效果尺寸为源 PNG 像素。像素层和文字保留原缓存，效果随整层几何缩放；形状在缩放时重新生成对应文稿尺寸的缓存，因此形状效果保持文稿像素尺寸，与圆角、线宽的规则一致。投影 90° 向下，按官方角度约定计算偏移。画布扩展不填充结构层 PNG 边界，避免下一次编辑时内容框错位。改变源像素网格时必须核对效果单位：仅缩放几何无需再缩放效果参数；确实重采样源图时才按所采用的网格调用 `try effects.scaled(by:)`，超范围原子拒绝。

效果同样冻结源稿、采用共享串行队列并合并最新请求。临时工作面保守按填充后像素的 32 字节及源图额外 8 字节估计，单边/像素上限继续生效；组蒙版嵌套预算还预留最多 64 MiB 的效果缓存，超限在分配前拒绝。缓存最多 32 项，源图、蒙版或参数变动使缓存失效。取消或无操作不清空重做，完成后一步撤销恢复原参数。

## 资源、事务与像素编辑

沿用官方 Compositor 的“PNG 缓存 + text/shape 元数据”设计；源 PNG 用于显示和导出，参数独立保存，重开后继续可编辑。文字和形状互斥，不能混入组或调整层记录。图层 ID、层序、父组、剪贴引用、数值蒙版及普通几何保持现有约定。

绘画、填充、像素调整或选中像素变换前，必须先在图层面板选择“栅格化为像素层”；该操作保留当前外观并可撤销，撤销后恢复文字/形状结构。直接修改图层蒙版、整层几何、复制及组整理保留编辑参数。合并与盖印通过正式渲染器，源层除非主动合并不会被压平。

带有任何已存效果参数（含已关闭效果）的层暂不支持选中像素变换及四角透视/扭曲；像素重采样会改变效果所依附的坐标系，直接保留参数会让投影方向或尺寸跳变。先移除效果或使用盖印副本后再操作，取消选区仍可自由变换整层；失败保留原图、效果、选区及重做历史。四角工具的拒绝入口在对应功能集成时统一接入。

面板冻结整个源文稿及图层选择；源稿、工具、目标或文稿改变后，过期任务不能提交。内容、调整和效果预览共用串行队列，快速修改合并到最新请求；取消后的旧队列项不会开始分配，正在运行的项完成后才让下一项进入。正式保存、导出和 AI 仅使用已提交文稿。

继续执行单表面 4096 单边/1600 万像素与有界历史保护；文字最多 10 万 UTF-16 单元，参数和局部样式还受文稿元数据预算限制。未知嵌套字段、非法字体名、无效范围和不支持的记录拒绝，不删除后假装成功载入。

## 来源与验证

已核对官方固定提交 `365b5745eda537f984f3d5bed1e53c361dbc9c91` 的 `Document/TypeTool.swift`、`ShapeTool.swift`、`LayerEffects.swift`、`Rendering/LiveMaskRenderer.swift` 和 `docs/project-format.md`。数据、圆角和效果算法按文件标注 MIT 来源；AppKit 的字体/文本视图改为 CoreText、UIKit 字体选择器和 SwiftUI 参数面板。

核心回归覆盖中文多行与局部样式、缺字体的 PNG 保留、层序/组/剪贴、新建/重编/空操作历史、几何缩放后的圆角、显式栅格化与撤销、严格字段和版本拒绝、跨工具预览分配串行与取消。效果另覆盖软蒙版只乘一次、六效果参数与保存、扩边合并、剪贴成品 alpha、旋转/翻转投影方向、内效果覆盖、形态学参考核对、预览蒙版替换缓存与预算拒绝。原生流程和 UI 回归单独核对；模拟器与合成画稿不能代替真实字体和触控体验验收。

真机检查：新建中文段落并换行，切换字体和字号，取消后核对原稿；再完成并一步撤销/重做。创建圆角矩形，缩放后核对圆角，再保存退出并横竖屏重开；参数继续可编辑。给文字/形状绘制蒙版并撤销，显式栅格化后绘画，再撤销恢复结构。缺字体样例须提示而不是自动替换原外观。

效果真机检查：文字和形状分别添加内/外描边、投影、发光，快速修改参数后取消；重新编辑并完成，保存重开检查参数；给带效果的层加软蒙版，再添加剪贴子层，观察边缘与外描边都保持正确覆盖。横竖屏检查面板滚动、键盘遮挡、完成/取消，以及后台切换后的旧预览取消。未进行真机验收前不得把模拟器通过等同触控体验完成。


数值输入会立即更新有效预览，编辑中的文字草稿在后台预览刷新时保留。空值、非法数值或超范围输入显示提示并阻止“完成”；失焦或回车后显示已接受参数的规范值。新会话及切换效果种类重新建立数值输入状态，不沿用旧草稿。圆角回归保留原快速输入、切换平滑、提交、缩放和重开顺序，不增加读值等待来掩盖输入时序问题。

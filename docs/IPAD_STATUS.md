## 格式与能力边界

1. `.comp` 清单和图层资源使用上游 v14 格式；另有 `ipad-state.json` 与可选 `selection.png`。上游重新保存可能移除这些 iPad 专属状态，不能把锁定、任务收据和选区宣称为跨编辑器标准字段。
2. `.comp` 接受已实现的栅格、曲线/色阶调整层、文字、形状、六种效果和辅助线子集，PNG 缓存与参数分别保存。未知嵌套字段、其他调整/效果、不支持的跨组/链式/分离实时蒙版、未链接蒙版、未知组蒙版或调整层合成语义、16 位/HDR 和其他混合模式明确拒绝，避免静默损失。PSD 使用更窄的交换子集，不携带这些可编辑文字、形状、效果或调整参数。
3. 初版渲染上限为每边 4096 像素、每个栅格面最多 1600 万像素。大文稿、多个大图层和长笔迹的响应时间、内存峰值仍待真机测量；目前没有 Metal 分块渲染或磁盘历史交换。
4. 曲线/色阶使用可再次编辑的调整层；已有亮度/对比度/饱和度/模糊仍是可撤销的像素操作。普通整层/整组仿射变换保留可编辑结构；选中像素及透视/四角重采样前要求文字/形状显式栅格化。“同时缩放图层”改变栅格几何、保留原 PNG 和效果参数；文字/形状也须先显式栅格化。多层选中像素变换、网格变形和液化仍未实现。
5. 选区保存为单一灰度覆盖蒙版；已支持两种套索、组合、羽化、魔棒、Vision 对象/主体和数值扩缩，不保存可重新编辑的矢量路径。手绘快速选择笔、边缘精修和多层透视仍未实现；Vision 质量需真实输入验收。
6. PSD 仅支持 v1/RGB8/raw 或 PackBits 和已验证的栅格/穿透组/蒙版/剪贴组合；有独立蒙版时仅接受原图与蒙版同网格、1:1 大小、整像素正交变换。非正常混合剪贴层配软 Alpha、启用灰度蒙版或部分透明基底拒绝。PSB、完整智能对象/文本/矢量/效果往返、CMYK、16/32 位/HDR、完整 ICC 工作流、贝塞尔路径、仿制/修复、更多调整和滤镜仍待后续。PSD RGB ICC 转 sRGB8 不等于保留原颜色模式。
7. AI 后端仍为参考图编辑后应用输出蒙版。没有取消或百分比进度接口；客户端不会显示虚假的取消能力或偷偷切换模拟后端。旧版本候选须明确确认才按原位置加入；画布尺寸变化或坐标不兼容仍拒绝。候选删除只处理已结束任务，不承担生成取消。
8. ZIP 快照是不可变备份，不是双端实时同步；目前没有服务器历史备份恢复浏览界面，也没有自动跨设备编辑冲突合并。

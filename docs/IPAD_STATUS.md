选中组及后代只携带一次，包括隐藏层、启用/停用的组蒙版和普通层链接蒙版；PNG、数值灰度、UUID、层序、透明度和剪贴引用保留。单独变换剪贴层或基底可改变相对位置，未选中的祖先蒙版保持原位。任一被携带项目或祖先锁定时整次拒绝。有活动选区时要求先取消选区，不退回全层操作；单普通层的选中像素变换不变。

非直角旋转层共同非等比缩放会产生斜切，当前格式不支持，因此界面强制锁定比例，核心另行检查两轴垂直。此处与上游自动丢弃斜切的近似不同；尺寸、位置和组蒙版临时内存预算超限整次拒绝。入口、上游差异与真机步骤见 [共同变换说明](IPAD_MULTI_LAYER_TRANSFORM.md)。

验证：完整 SwiftPM **193 项（3 项 HTTP 集成按环境跳过、0 失败）**；最终原生 **108 项**、UI **15 项**各完整通过，新增核心 16 项、原生流程 9 项及 UI 2 项。覆盖仿射映射参照、所有翻转组合、精确平移、斜切/尺寸/锁定/陈旧状态拒绝、隐藏子树去重、软组蒙版与剪贴合成、一次撤销、无操作保留重做和分层读写。UI 实际完成多层缩放/旋转/移动/双轴翻转、组蒙版随动、取消/无操作、重做和横竖屏重开；截图已目视核对。

首轮完整原生测试中，旧层面板断言仍按“多选禁止自由变换”准备；已更新为检查共同预览同时移动全部所选层，继续保留绘画/单层调整拒绝、取消后原稿与历史不变的断言。应用代码未因该旧断言失败而改变；更新后重跑完整 108 项原生测试通过，15 项 UI 在同一应用代码上完整通过。本轮未修改桥接协议，验证均使用隔离模拟器与合成画面；实际 Pencil 操作与大画稿性能仍需真机体验。

## 格式与能力边界

1. `.comp` 清单和图层资源使用上游 v14 格式；另有 `ipad-state.json` 与可选 `selection.png`。上游重新保存可能移除这些 iPad 专属状态，不能把锁定、任务收据和选区宣称为跨编辑器标准字段。
2. 仅接受可保真的栅格子集。未实现的文本、形状、调整、效果、辅助线、不支持的跨组/链式/分离实时蒙版、未链接蒙版、未知组蒙版合成语义、16 位/HDR、其他混合模式及未知字段均明确拒绝导入，避免静默损失。
3. 初版渲染上限为每边 4096 像素、每个栅格面最多 1600 万像素。大文稿、多个大图层和长笔迹的响应时间、内存峰值仍待真机测量；目前没有 Metal 分块渲染或磁盘历史交换。
4. 调整是可撤销的像素操作；“同时缩放图层”改变图层几何，保留原 PNG，并非重新采样源图像。合并会固定源层的当前像素外观，可通过撤销恢复源层；其适用范围见上一节。已支持整层/整组共同变换；当前无非破坏性调整图层、多层选中像素变换、网格变形或透视工具。
5. 选区保存为单一灰度覆盖蒙版；已支持两种套索、组合和羽化，但不保存可重新编辑的矢量路径。魔棒、快速选择及边缘精修仍未实现。
6. 文字/矢量形状、仿制/修复/液化、曲线/色阶、完整滤镜和图层样式、PSD 导入导出、ICC/CMYK/16 位/HDR 工作流仍在后续范围。
7. AI 后端仍为参考图编辑后应用输出蒙版。没有取消或百分比进度接口；客户端不会显示虚假的取消能力或偷偷切换模拟后端。旧版本候选须明确确认才按原位置加入；画布尺寸变化或坐标不兼容仍拒绝。候选删除只处理已结束任务，不承担生成取消。
8. ZIP 快照是不可变备份，不是双端实时同步；目前没有服务器历史备份恢复浏览界面，也没有自动跨设备编辑冲突合并。

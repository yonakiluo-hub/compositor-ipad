# iPad 客户端状态

更新日期：2026 年 10 月 20 日（Asia/Shanghai）。

本次已从预留目录建立原生 iPad 应用、可保存重开的分层文档核心、Pencil/触控输入、离线编辑及现有桥接的原生 Swift 客户端。它是 [产品需求](PRODUCT_REQUIREMENTS.md) 的首个基础实现，完整 Photoshop 常用功能覆盖仍需继续开发。

## 验证记录

- 文档核心 11 项测试通过，覆盖事务回滚、空操作保留重做、Int64 溢出和大于 2^53 的精确读写、图层组/锁定/循环检查、候选错误文档/版本/几何防护、一次插入撤销重做、去重持久化、分层工程原子覆盖、损坏或不支持内容拒绝，以及同标识外部工程导入不会覆盖本机新版本。
- ZIP 归档 3 项测试通过，以独立系统 ZIP 读取器验证 CRC/归档结构，验证固定时间戳产生相同字节，以及大小限制、危险名称和符号链接拒绝。另用 Python `zipfile` 验证了原生客户端产生的 3350 字节、5 文件合成归档，并经原生 Swift 客户端通过模拟桥接完成上传、重复上传、列表及原字节下载。
- `.comp` 双向兼容样例通过：把 iPad 生成的含图层组、组不透明度、带蒙版栅格层、Multiply、旋转/翻转和空白层的工程交给上游真实 `ProjectStore` 读取并重新保存，再由 iPad 核心重新读取。上述标准字段和资源保留；上游重存会删除 iPad 专属选区与状态。这只验证已实现的栅格子集。
- 渲染 11 项、桥接 11 项测试通过，覆盖像素方向、变换/选区/alpha 合成、协议、原始字节持久化及真实/模拟 HTTP 链路；新增灰度选区保存、解码、裁切、重编码的回归，保持 0/128/255 数值并移除 ImageIO 附加的颜色元数据。常规离线测试会跳过需私有环境的 2 项网络集成测试；本轮另配置环境执行通过。
- 原生应用与测试 target 构建成功；iPad 模拟器的 6 项笔刷测试和 1 项界面测试通过。界面流程覆盖绘画、新建图层、撤销/重做、保存、退出与重新打开后恢复。
- 原生 Swift 网络客户端已通过真实 Windows 桥接的合成 32×24 输入生成闭环，耗时约 5.544 秒。模拟器应用内也完成了 1200×900 合成笔迹文稿的局部选区生成、候选预览、加入第三个图层、一步撤销与重做，以及 31 KB 分层工程备份。退出重开后图层与配对保留；随后 Windows 服务不可达，任务恢复明确提示连接错误，未丢失本地文稿。这是链路与状态验证，不是实际绘画质量或普遍推理耗时的保证。
- 真机应用已签名构建并安装到 iPad Pro 11 英寸（第三代，iPadOS 26.5.2）；签名、设备标识和描述文件匹配，首次启动仍待用户在设备上信任开发者。模拟器构建和界面测试不能证明真实 Pencil 延迟、倾斜效果、防误触、锁屏恢复和持续内存表现。

构建、测试和配对入口见 [客户端 README](../ipad_app/README.md)。测试用画面均为合成内容；配对信息、用户画稿、生成结果、签名资料和运行数据库不纳入仓库。

## 格式与能力边界

1. `.comp` 清单和图层资源使用上游 v14 格式；另有 `ipad-state.json` 与可选 `selection.png`。上游重新保存可能移除这些 iPad 专属状态，不能把锁定、任务收据和选区宣称为跨编辑器标准字段。
2. 仅接受可保真的栅格子集。未实现的文本、形状、调整、效果、辅助线、剪贴链接、未链接/组蒙版、16 位/HDR、其他混合模式及未知字段均明确拒绝导入，避免静默损失。
3. 初版渲染上限为每边 4096 像素、每个栅格面最多 1600 万像素。大文稿、多个大图层和长笔迹的响应时间、内存峰值仍待真机测量；目前没有 Metal 分块渲染或磁盘历史交换。
4. 调整是可撤销的像素操作；“同时缩放图层”改变图层几何，保留原 PNG，并非重新采样源图像。当前无非破坏性调整图层、网格变形或透视工具。
5. 选区当前支持单一覆盖蒙版；尚未完整实现套索、魔棒、快速选择、边缘精修与羽化面板。
6. 文字/矢量形状、仿制/修复/液化、曲线/色阶、完整滤镜和图层样式、PSD 导入导出、ICC/CMYK/16 位/HDR 工作流仍在后续范围。
7. AI 后端仍为参考图编辑后应用输出蒙版。没有取消或百分比进度接口；客户端不会显示虚假的取消能力或偷偷切换模拟后端。旧版本候选只保留预览，不强制套用到已变化文稿。
8. ZIP 快照是不可变备份，不是双端实时同步；目前没有服务器历史备份恢复浏览界面，也没有自动跨设备编辑冲突合并。

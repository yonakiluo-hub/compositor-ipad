# iPad 曲线、色阶与可编辑调整层

本轮在多层共同变换基础上开发；能力、自动测试和真机体验分别记录于 [状态文档](IPAD_STATUS.md)。普通调色、保存及导出离线可用。

## 操作入口

- 顶栏“调整图层”菜单 → “新建曲线调整层”或“新建色阶调整层”。选中已有调整层后，同一菜单的“编辑调整层”或图层面板“编辑参数”可再次打开。
- 曲线支持 RGB、红、绿、蓝四组控制点。点按曲线区域添加、拖动控制点；可用“下一个控制点”、输入/输出滑杆和删除按钮精确选择与修改。端点输入固定为 0/255，内部点不能交叉，每通道 2–32 点。
- 色阶每通道提供输入黑场、输入白场、中间调 gamma、输出黑场与输出白场。输出端点可反转；输入黑场始终低于白场。
- “重置当前通道”只重置当前通道。完成前仅显示预览；完成一次事务，取消不改文稿。新建时参数仍为恒等映射不会添加空调整层；仅切换通道不清除重做。
- 横屏宽面板并排显示整稿预览与参数，竖屏可滚动查看。原有亮度、对比度、饱和度及模糊像素调整仍在同一菜单中。

## 参数与像素

优先适配官方 Compositor 固定提交 `365b5745eda537f984f3d5bed1e53c361dbc9c91`：

| 上游文件 | 接入内容 |
| --- | --- |
| `Document/Curves.swift` | 四通道参数、控制点校验、保形三次 Hermite 插值；局部极值的斜率为零，避免过冲；iPad 使用等价的稳定谐均值避免极平曲线的倒数溢出，并拒绝斜率不有限的极近控制点。 |
| `Document/Levels.swift` | 黑白场、gamma、输出范围；单颜色通道先执行，再执行 RGB 总通道。 |
| `Document/LayerAdjustment.swift` | `Levels`/`Curves` 类型和独立参数记录，调整层无源 PNG。 |
| `Rendering/LevelsPixels.c` | Float 查找表、直通道颜色上的插值、按 alpha 还原到预乘颜色。 |
| `CompositorTests/LevelsTests.swift`、`AdjustmentLayerTests.swift` | 通道次序、透明边、蒙版、图层顺序、重开与再次编辑等行为样例。 |

iPad 核心在 `Core/ColorAdjustments.swift` 与 `AdjustmentLayerEdit.swift`，像素处理在 `Rendering/ColorAdjustmentRaster.swift`。保留 MIT 与文件级来源；AppKit 会话和桌面面板不搬入 UIKit。

每个通道建立 256 项 LUT；半透明颜色先除 alpha，在相邻 LUT 项间插值，映射后乘回原 alpha。alpha 和全透明覆盖保持不变；蒙版及调整层不透明度只插值颜色，不产生新的像素覆盖。恒等调整直接跳过，避免重复往返损伤软边。

## 作用范围

1. **普通调整层**：在当前绘制位置修改已有的下方合成结果，不影响上方后来绘制的图层。无蒙版时覆盖整个已有结果；不使用调整层的占位几何裁切颜色。
2. **穿透组**：延续 iPad 当前穿透规则。组内调整层可以看到已经绘制的组外背景；祖先组透明度乘入调整强度。需要局限单层时可创建剪贴关系。组蒙版仍对进入/离开组前后的结果插值一次，嵌套由内向外。
3. **剪贴调整层**：可剪贴到同组连续普通栅格基底，作用于该堆栈当时的颜色。基底原始 alpha 最后恢复一次，半透明轮廓不会增厚；隐藏基底会隐藏整个堆栈。调整层不能成为剪贴基底。上方后续剪贴层仍按自身顺序绘制。
4. **选区和蒙版**：新建时把当前数值灰度选区原样保存为调整层蒙版，全黑选区保留为全黑，不解释为无选区。再次编辑参数保留已有蒙版，不重复乘当前选区。蒙版可使用现有绘画、填充、反相、启停、删除和载入选区入口；蒙版绘画仍受当时选区约束。
5. **整理与变换**：图层整理、复制和组复制保留参数及剪贴引用。整组/多层变换携带调整层蒙版；无蒙版的调整层不扩大共同包围框。调整层本身没有可移动或涂画的源像素，单层自由变换不开放。
6. **合并与导出**：包含调整层的源集合暂不直接合并，防止依赖集合外的下方内容时改变外观。可创建隐藏的画布盖印副本；PNG/JPEG、AI 输入及盖印共用正式文稿合成结果，未完成预览不会写入。

当前调整层只接受正常混合；其他调整类型、调整层混合模式、隔离组、跨组或链式剪贴、自动色阶、直方图、取样滴管及预设不在本轮范围内。

## 事务、预览与文件

- 编辑器冻结整个源文稿和图层选择。任一源层、文稿、选择或编辑目标改变，旧编辑器不能提交。工具切换、撤销/重做、切文稿和后台会取消预览；未开启调色会话的取消不发布无关界面更新。
- 后台最多运行一项预览，拖动期间合并为最新参数；过期结果不能写到新会话。预览失败保留源文稿并显示错误；完成前重新验证与合成，成功后一次提交。
- `.comp` v14 清单采用标准 `adjustment`、`levels`、`curves` 字段；同时写出上游要求的中性 HSV 字段。原 PNG、灰度蒙版、图层 UUID、层序与参数分别保留。
- iPad 状态文件记录 `adjustmentCompositing: pass-through-lut-v1` 并绑定清单摘要。含调整层但缺少该标记的外来工程明确拒绝；这不是完整上游调整层互导承诺。未知类型或任一未知嵌套参数拒绝，不能静默丢弃后再保存。
- 继续执行 4096 单边/1600 万像素画面限制；调整在已有颜色表面处理，仅蒙版需要额外 L8 覆盖表面。组蒙版预算计入嵌套调整覆盖，不取消原内存保护。大画稿持续交互性能仍需目标 iPad 实测。

## 回归与真机检查

自动回归覆盖恒等/反相/通道次序、Hermite 极值、低 alpha、软蒙版、普通与剪贴层顺序、穿透组及嵌套组蒙版、选区捕获与再次编辑、锁定、无操作重做、过期会话、工程读写与备份、蒙版预览和资源保留。触控测试实际添加/拖动曲线点、调节色阶、剪贴、添加蒙版及横竖屏重开；最终结果见状态文档。

真机建议：

1. 在一份副本中添加色阶层，分别改 RGB 与单通道，取消后确认画稿不变；再完成并一步撤销/重做。
2. 用套索和羽化选区创建曲线层，确认作用边界；取消选区后再次编辑，软边不得加重。用 Pencil 绘制调整层蒙版并撤销。
3. 将调整层剪贴到半透明基底，在其上下增加图层、切换显隐和次序；核对轮廓和作用范围。
4. 保存、退出并横竖屏重开；参数和控制点继续可编辑，原层仍可绘画，PNG/JPEG 导出一致。长时间拖动与大画稿的响应、发热和后台恢复单独记录。

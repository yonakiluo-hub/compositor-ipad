# 图层组整理

本轮范围（2026-10-21）：已有图层或完整子树的批量移入、移出组；同父组连续项目成组；指定目标组的顶部、底部或某个同级项目上方/下方。移动采用画面中的自下而上次序，选中组及其后代时只移动组根一次。成组保留原同级位置；跨组或不连续成组暂不支持，可先通过移动整理。

规则：

- 每次预检完整目标结构，再通过一次文稿事务提交；失败、取消和无操作保留文稿及重做。原图层 UUID、PNG、独立蒙版、几何和剪贴引用不变。
- 完整剪贴堆栈一起移动或成组；缺少基底/任一剪贴层，或插入位置会拆散其他堆栈，整次拒绝。不会自动释放或改绑关系。
- 所选子树任一项目或祖先锁定时拒绝；目标组或其祖先锁定时拒绝。可以放在锁定同级项目旁边。隐藏项目可以整理，保留自身显示开关。
- 不能移入自己或后代。移出组要求去重后的根项目同属一个父组，放在原父组上方；保留空组。
- 跨父组移动会继承新祖先的显示与透明度，并改变叠色上下文，画面可能改变；不补偿透明度或烘焙像素。面板明确提示。成组创建正常、可见、100% 不透明的穿透组。
- 面板固定打开时的文稿、版本与选择；期间变更后须重新打开。选择属于导航，不另建历史。

来源：对照官方 Compositor `365b5745eda537f984f3d5bed1e53c361dbc9c91` 的 `Document/LayerGroups.swift`（根节点去重、绘制次序、相对位置和移出组）。iPad 增加整批预检、严格剪贴依赖与锁定规则，不采用上游自动解除剪贴的移动行为。许可与原始 NOTICE 见仓库 `licenses/`。

组蒙版、多层共同变换、解散组及拖拽排序不在本轮范围。

## 真机验收步骤

1. 离线打开合成画稿，选择同组连续的两个图层，打开图层面板顶部“整理图层”→“成组”→“应用”。确认组内上下遮挡与原画面一致。
2. 一次撤销恢复原图层及次序，重做恢复新组；保存、退出和重开，确认结构及蒙版保留。
3. 选中某个子层，“移出组”后应位于原父组上方。再从“移动”指定目标组，以及某个同级项目下方，确认层序；分别测试撤销/重做。
4. 完整选择剪贴基底及全部剪贴层一起移动；单选其中一层时应出现原因且不能应用。确认没有自动释放剪贴。
5. 隐藏一层后整理，其开关保留。锁定子层后尝试移动整个组，应整次拒绝。移入隐藏或半透明的组后，确认画面遵循新祖先设置；这是预期行为。
6. 横竖屏打开整理面板，取消和移到原位置都不应清掉已有重做。

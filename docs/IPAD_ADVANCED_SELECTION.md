# 图像选区与四角几何

本模块优先适配官方 Compositor 固定提交 `365b5745eda537f984f3d5bed1e53c361dbc9c91` 的 `MagicWand.swift`、`WandPixels.c`、`ObjectSelection.swift`、`Selection.swift` 与 `Distort.swift`；保留现有 MIT 许可证。桌面会话和 AppKit 输入不搬入 UIKit。

## 图像选区

- 工具栏“魔棒”：点按取样，容差 0–255，单点/3×3/5×5平均；“连续”使用四连通扫描线填充，关闭后选择全图所有匹配像素。逐通道比较预乘 RGBA，包括透明度，与上游 `wand_mask` 一致。直接生成数值 L8 覆盖，不构建巨大轮廓路径。
- “可见合成”读取正式文稿合成，包含已提交效果；关闭后读取当前普通层原像素的当前几何，不乘图层透明度、混合、剪贴、蒙版或效果。文字/形状使用当前 PNG 缓存；调整预览、内容/效果预览或四角草稿不会成为取样源。
- “对象选取”：点击前景对象，或按“选取全部主体”。真实调用 iOS 17+ Vision 前景实例请求并读取实例蒙版；没有对象/模型不可用明确提示，原选区保留。不会用色彩阈值代替主体识别。实际识别质量和大图耗时需真机真实画面验收。
- 图像选区支持新建/添加/减去/相交，沿用数值 max/饱和减/min 和统一羽化。操作冻结文稿、图层选择、设置和目标；文稿、工具、设置或后台切换后旧任务不得提交。计算成功一次事务，像素资源不改；重复相同覆盖不清除重做。
- 选区操作菜单“扩展或收缩选区”：0–100 像素。以方形邻域在现有 L8 覆盖上作 max/min；使用单调队列，半径不增加每像素工作量。画布外为 0，收缩全选会缩离画布边界，缩为空仍是显式黑色选区；灰度强度不改成全白，也不会重新羽化。该数值形态学与上游矢量路径描边并不逐点相同。

普通手指点按可使用魔棒/对象选取；拖动仍用于平移，不能先提交选区再开始平移。Pencil 点按同样可用。撤销、保存、重开与原有绘画/填充/调整/AI 共享同一选区。

自动化覆盖连续/全图、RGBA容差、平均取样、透明背景、灰度扩缩/边界、选区组合、一次事务、取消/过期结果、工程保存和 UI 重开。实际 Vision 模型输出不作为确定性像素断言；原生工作流通过注入确定性蒙版验证事务和错误路径，生产入口仍使用真实 Vision。

## 透视与四角扭曲

顶栏“透视与扭曲”菜单提供“透视”和“四角扭曲”。透视拖动角点时沿主要边方向对称移动同边另一角；扭曲可独立移动四角。框内拖动平移，底栏可切换角点、用滑杆调整，或精确输入 X/Y 后点“应用坐标”；也可切换模式、重置、取消或完成。坐标草稿未应用、非有限、越界或会折叠四角时不可完成。四角扭曲精确应用成对 X/Y；透视仍按主要边方向投影并联动同边角，应用后显示实际坐标。角点顺序为左上、右上、右下、左下，旋转图层沿其原始几何编号。

- 没有选区时处理当前单个普通层全部像素及其链接蒙版，保留图层 ID、顺序、剪贴关系、透明度、混合、可见性及蒙版启用状态。蒙版不烘焙到源像素；几何覆盖进入图像 alpha，独立灰度蒙版只保留其数值强度，避免抗锯齿重复压暗。
- 有选区时沿用冻结选中像素与补集：灰度软切，重叠位置先补回被切走的覆盖，再按预乘 alpha 合成。选区 L8 一次移动、不重复羽化；图层独立蒙版固定在文稿原位置。旋转/缩放/翻转或不同分辨率蒙版需要时，先冻结一次到文稿像素网格；取消和回到原角点仍恢复原始资源。
- 逆投影采样保留最近邻；平滑与高质量模式均使用双线性采样。凸四边形边界使用独立几何覆盖抗锯齿；不扩散画布外的选区。提交后生成轴对齐 PNG 与几何，不引入新 `.comp` 字段。
- 文稿及所选图层冻结，拖动只替换合成预览。后台任务串行合并最新请求，旧请求、旧会话、文稿变化或工具切换不能发布结果。保存、导出和 AI 继续读取正式文稿。完成一次事务，取消、重置后完成、原位完成及拒绝操作均保留已有重做。触摸中断只撤回该次拖动，不覆盖后续数字调整或新会话。
- 明确拒绝交叉、折叠、凹四边形、重合角点、透视奇点、锁定层、组/调整层、多层共同扭曲、空选区或选区内无像素。输出仍受 4096 单边/1600 万像素限制；不会把不支持场景压平近似。已有自由变换继续负责多层普通仿射几何。

核心像素回归覆盖 homography 角点与逆映射、远离原点的数值稳定、退化/折叠/奇点和容量限制、透视同边联动、翻转和非对称灰度蒙版、软边抗锯齿、灰度选中像素补回、固定独立蒙版、一次重网格及原位资源恢复。原生测试准备了预览与提交像素一致、一次撤销、正式保存/重开、取消/重置保留重做、过期结果和触摸中断；UI 测试覆盖真实角点拖动、非法/越界/折叠坐标拒绝、成对坐标应用、同坐标控制点切换时清除旧草稿、取消、提交、撤销与旋转重开。

完整整合验证及真机状态见[状态记录](IPAD_STATUS.md)。生产 Vision 已在 Mac 的双主体合成图上实跑，验证实例坐标与软 L8 合并；确定性工作流测试仍使用注入蒙版，不把合成样例推断为真实照片质量。

## 与可编辑内容和效果的整合

第 5 部分已统一接入这些保护：文字/形状的选中像素及四角变换必须先通过图层面板显式栅格化，禁止重采样 PNG 后保留不匹配元数据。任何非空图层效果参数（含已关闭效果）会阻止选中像素及四角变换，避免重新建立像素网格后改变投影方向和大小；可先移除效果或使用盖印副本，取消选区仍可变换整个图层。普通整层仿射几何继续保留可编辑参数与效果；形状缩放会按新文稿尺寸重绘自身缓存。拒绝操作不改变原稿或重做历史。

原层取样的临时副本已明确排除效果，使用可编辑文字/形状的 PNG 缓存；可见合成包含已提交效果。内容、效果、调色、图像选区和四角预览共用串行队列，切工具、目标或后台取消旧会话，保存、导出和 AI 仍读取正式文稿。详情见[文字、形状与图层效果](IPAD_EDITABLE_CONTENT.md)。

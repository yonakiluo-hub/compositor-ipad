# iPad 文件、裁切与辅助线

本轮提供文件菜单中的分层 PSD 子集、更多图片格式、保留框外像素的画布裁切，以及可保存的辅助线。原生 `.comp` 仍是完整编辑工程；PSD 是受约束的交换格式。图片、PDF 和 PSD 合成预览均从已提交文稿生成，裁切草稿与辅助线显示不会混入正式像素或 AI 输入。

## 使用入口

- 文件菜单 → **PSD 与其他格式**：打开分层 PSD，或导出分层 PSD、透明 TIFF、单页图像 PDF。PSD 打开为新的可编辑文稿，原文件保留；失败时不替换当前文稿。切换前沿用现有自动保存失败保护。
- **导入图片为图层**：接受设备 ImageIO 当前支持的 PNG、JPEG、HEIC、HEIF、TIFF、WebP。导入先检查文件大小、帧数、尺寸、位深与颜色模式，再解码，按 EXIF 1–8 正向化，转换为工作空间 sRGB8，并保存透明 PNG 图层缓存。原图片不改写。
- **裁切画布（保留框外像素）**：输入左上角 X/Y、宽/高，或应用原比例、1:1、4:3、16:9，点“更新预览”核对结果，最后点“完成”。负坐标允许扩展裁切框，再次显露保留的图层内容。
- **辅助线**：按文稿像素添加水平/垂直线，选中已有线输入新位置，或删除/清空。显示开关只影响画布，不增加历史；线的位置和 UUID 保存在 `.comp`。

## PSD 可交付范围

读取遵循 PSD v1、RGB、8 位、3/4 合成通道，支持未压缩与 PackBits；写出使用未压缩通道。读写均按标准自下而上记录层序：组边界 type 3、组内子层、最后为具名 folder type 1/2；组与嵌套层序须由独立工具验证，不能只做自身读写往返。文件包含真正的逐层 RGB/Alpha 通道和完整合成预览，没有把一张平面图伪装为分层工程。

可交换普通栅格层、Unicode 名称、显隐、锁定、8 位不透明度、Normal/Multiply/Screen/Overlay/Darken/Lighten/Difference/Exclusion/Hue/Saturation/Color/Luminosity、同组连续剪贴栈，以及链接数值图层蒙版。组只接受无组蒙版、100% 透明度的穿透组；嵌套、隐藏状态和层序保留。iPad 的组透明度和组蒙版有自己的穿透语义，不能按普通 Photoshop 组蒙版猜测转换。

剪贴支持矩阵（导入、导出使用同一能力边界）：

| 剪贴子层混合 | 基底最终数值覆盖 | 结果 |
| --- | --- | --- |
| Normal | 允许现有软 Alpha、数值蒙版及不透明度 | 支持 |
| 其他已支持混合 | 所有非零覆盖均为全覆盖；允许硬透明孔洞 | 支持 |
| 其他已支持混合 | 任一像素满足 `0 < 覆盖 < 1` | 明确拒绝，提示保留 `.comp` |

覆盖判定包括图像 Alpha、启用的灰度蒙版、基底不透明度及导出变换产生的抗锯齿。停用的蒙版不参与当前覆盖。检查复用已解码/已准备的 Alpha 和数值蒙版，不为判定重复解码 PNG 或分配另一张全画布。不能把已知存在明显差异的组合仅列为量化误差后继续导入或导出。

写出普通层时显式设置 Adobe `clbl`（Blend Clipped Layers As Group）为 true。读取 false、未知布尔值、非零填充或错误长度会拒绝；缺失字段使用 Photoshop 默认的成组剪贴语义，默认行为依据 [Adobe 混合选项说明](https://helpx.adobe.com/ca/photoshop/using/layer-opacity-blending.html)。不会因第三方工具暂未实现该字段而改变原生合成规则。

组开闭记录可以携带非空边界框；该框只作为结构元数据读取，不按其尺寸分配像素或改动子层几何。组记录必须无蒙版、无实际像素通道；允许零个通道或只有合法 raw/PackBits 压缩头的空通道。所有组通道在任何图层像素解码之前预检，空通道直接跳过。

源图与蒙版矩形不同时，导入扩展为它们的并集：图像补透明，蒙版按 PSD 默认值补齐。不会按画布裁掉负坐标或框外源数据。PSD 不记录本客户端的旋转/采样元数据；导出普通层会把完整几何范围烘焙为独立栅格层，保留框外范围，原 `.comp` 与源 PNG 不变。8 位转换、Alpha 与不透明度量化允许约 1–2/255 的样本误差，不承诺原始 PSD 压缩字节往返一致。

正交旋转的角点只有在整组角点接近整数网格时才先吸附整数，再计算输出范围，避免 `sin/cos` 浮点误差多分配一圈透明像素，或把合法 4096 边资源误报为 4097；真实亚像素边界仍保留其覆盖范围。

独立软蒙版在原生渲染中先乘入再采样。为避免“图像和蒙版分别采样后再相乘”改变边缘，带蒙版层导出仅接受原图与蒙版同分辨率、1:1 大小、整数像素角点和 90° 整倍数旋转/翻转；其他几何明确拒绝，保留原文稿。可编辑调整、文字、形状、效果、智能对象、未链接/相对/反相蒙版、蒙版密度/羽化、隔离组、挖空、自定义填充透明度、混合颜色带及未知关键字段均不在子集内。当前没有自动压平或自动移除元数据的兜底导出。

ICC 图像资源 1039 会作为源 RGB 配置转换到 sRGB8；缺少配置时按 sRGB 解释。无效、非 RGB 或 HDR 配置拒绝。写出嵌入 sRGB ICC；数值蒙版不经过颜色转换。分辨率资源要求方形像素、相同横纵 DPI；辅助线使用官方资源 1032，位置必须可由 1/32 像素精确表示。其他小数位置在 `.comp` 中可保存，PSD 导出会说明无法精确表示。

已知不影响像素的 UI/预览/XMP 资源可以跳过，不作为原生可编辑元数据保留；未知图像资源和附加图层字段拒绝。当前不导入或导出完整 Photoshop 元数据、专色、附加 Alpha、CMYK、Lab、16/32 位、ZIP、PSB、矢量或文本编辑结构。

文件限 256 MiB；画布和单张资源单边最多 4096、总计 1600 万像素；PSD 扩展后的图层和蒙版合计最多 3200 万样本、1024 个图层/组边界记录、64 层嵌套。导出先预检资源范围和总预算，再分配；错误长度、越界、坏 RLE 行、重复记录、未闭合组与超限均整次失败。

## 其他格式边界

TIFF 为单页、8 位 sRGB、LZW 压缩并保留透明度和文稿 DPI。PDF 为一页合成图像，页面点尺寸按 `像素 × 72 / DPI` 计算；没有可编辑文字、矢量或图层。PNG/JPEG 入口继续保留，JPEG 使用白底。

动画和多页图片、16/32 位、高动态范围或 HDR 增益图、CMYK 等不能直接导入，不会静默选首帧或降位深。HEIC/HEIF/WebP 入口随系统解码器可用性显示；不是新增独立编码器。此轮不支持 PDF 导入或多页选择器。

## 裁切事务与坐标

裁切会冻结完整源文稿、选择集合和会话 ID。预览不写入文稿、历史、保存或正式导出；完成先验证并渲染目标，再提交一次事务。取消、原位完成、非法范围与过期事件保留现有历史与重做分支。换文稿、切工具、撤销/重做、后台挂起会取消草稿；来源改变后不能把旧预览提交到新文稿。

完成只改变画布尺寸，并将所有普通层、隐藏层、组/调整蒙版的几何原点统一减去裁切左上角。UUID、层序、父组、剪贴引用、锁定和源图/蒙版 PNG 字节保持不变；不重采样源资源。锁定保护图层内容，不阻止整个文稿坐标系的裁切。裁切后的框外源资源仍保存在 `.comp` 中。

选区属于画布数值覆盖，按整数裁切坐标裁出 L8 样本，新增区域补黑；已经裁掉的选区样本不会在以后扩展裁切框时恢复。辅助线按相同原点平移，允许保留框外位置。普通画布改大小保持线的像素坐标；“同时缩放图层”的图像缩放按横/纵比例缩放对应方向的线。

辅助线使用现有视口的完整缩放、平移与旋转矩阵。显示线宽按屏幕点保持一致；旋转后的点到线段距离也有核心几何测试。当前管理入口为数值面板，尚未提供标尺拖出、画布拖线、吸附、网格和透视裁切。

## 验证与来源

核心回归覆盖独立手写 raw/PackBits PSD、通道截断与溢出、Unicode、透明度、框外矩形、蒙版并集、组/剪贴/隐藏、RGB ICC、严格拒绝、合成预览、全部 EXIF 方向、TIFF/DPI、PDF 页面、多帧/高位深/大文件预检，以及裁切数值选区、原 PNG 保留、一次撤销、取消/无操作重做、保存重开和旋转辅助线。原生工作流和 UI 回归分别覆盖实际 `EditorModel` 会话与菜单操作；模拟器编译不是这些测试已执行或真机验收的证明。

分层导出已用独立 Pillow/psd-tools 读取验证真实图层和合成 RGBA。可设置测试环境变量 `COMPOSITOR_PSD_FIXTURE_DIRECTORY` 输出纯合成 PSD 和原生参考 PNG，用独立工具检查实际 group 类型、父组、剪贴层序，并强制重合成。曾发现不同颜色的软 Alpha 基底 + Multiply 剪贴样例在 psd-tools 1.26.0 强制重合成中出现明显 RGB 差异；该组合现已在导入和导出两端明确拒绝。独立安全组合样例涵盖不透明基底 + Multiply、停用软蒙版、硬蒙版、Normal + 软基底及嵌套组：真实结构/层序/剪贴关系、显式 `clbl=true` 与强制重合成分别核对，不能只看合成预览。

PSD 逐层通道使用 straight RGB，而有透明度的合成预览使用白底预混 RGB：`预混 = round(颜色 × Alpha / 255) + 255 − Alpha`。读取无逐层记录、明确声明透明度的四通道 PSD 时去除该白底，三通道 RGB 不作此转换。独立中间色样例覆盖 Alpha 0/1/64/128/254/255：Pillow 读出的白底 RGB、psd-tools 去白底后的合成预览和强制逐层重合成分别验证，预乘 RGBA 误差不超过 1/255，逐层重合成精确一致。该样例曾发现直接写 straight RGB 到合成预览会使半透明棕色变暗，现已修复；纯色原色或不透明样例不足以发现此问题。Apple ImageIO 的 PSD 透明度/白底解释存在差异，不能用其解码标记推翻文件格式约定；图层通道不针对该系统解码行为改写。

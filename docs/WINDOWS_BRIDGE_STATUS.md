## 已验证

- 自动测试：62 项通过，另有 81 个子测试通过。覆盖图像和蒙版处理、认证、任务重试、提交状态不明时的恢复、服务重启、快照备份及不安全归档拒绝。

## 当前连接

Windows 桥接地址形如 `http://<WINDOWS_LAN_IP>:8190`；`<WINDOWS_LAN_IP>` 是占位符，实际地址从私下配对文件取得。ComfyUI 仅在 Windows 本机监听，例如 `http://127.0.0.1:8188`。地址可能随网络变化；本仓库不表示任何服务已启动或已安装为开机服务。

使用默认数据目录启动真实后端后，配对文件位于 Windows 的 `ipad_bridge/data-comfyui/pairing.json`，含私有访问令牌。**公开仓库与源码交接包不含此文件。** 真机联调时，由用户私下将它交给 Mac/iPad，令牌不要发到公开仓库或写进源码。

尚未验证 Mac 或 iPad 跨设备连接，未修改 Windows 防火墙。连接失败时先检查同网段、专用网络防火墙放行及 iPad 本地网络权限，不要开放公网端口。

## 当前限制

- 当前预设是“参考图编辑后应用输出蒙版”，蒙版尚不参与模型去噪。局部融合和绘画质量需要实际画稿评估。
- iPad 应用、Apple Pencil、撤销/重做、候选管理、iPad 锁屏恢复尚待 Mac agent 实现和真机测试。
- `.comp` 快照可以原字节备份和取回，但不代表已经验证所有 Compositor 图层类型可在 iPad 重开。
- 当前服务适合单个拥有者的本地开发使用，任务轮询、串行生成，无逐笔同步、取消任务或自动清理数据。

两条自动测试警告不影响通过结果：Starlette 提示未来切换测试 HTTP 客户端；拒绝重复 ZIP 项的测试故意构造了一个重复文件名。真实推理不使用测试客户端。

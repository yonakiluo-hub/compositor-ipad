# 多层与整组共同变换

本轮在组整理和组蒙版之上开发整层范围的共同移动、八手柄缩放、统一枢轴旋转、水平/垂直翻转。多选普通层、跨组/不连续项目或整个组均可；选中组及其后代时去重，完整子树只跟随一次。

## 规则

- 开始时冻结文稿、版本、完整源结构、活动层和选择集合；统一框为被携带普通层及组蒙版放置矩形的文稿坐标包围框，包括隐藏层和画布外内容。无蒙版的组没有独立像素几何，不扩大包围框。
- 整组携带全部后代和启用/停用的组蒙版。普通层的链接蒙版随层几何；未选中的祖先蒙版保持原位。PNG、灰度样本、UUID、层序、混合、透明度和剪贴引用保留。单独变换剪贴层或基底仍保持原依赖，可改变两者相对位置。
- 隐藏项目参与；任一被携带项目或其祖先锁定时整次拒绝。至少有一个被携带普通层含像素资源；空组或全部无像素资源不进入变换。
- 有活动选区时，多层/整组入口明确拒绝。请先取消选区，或只选一个普通层使用原有选中像素变换；不会默默改成全层操作。
- 现有格式只表示旋转矩形与翻转。任一源矩形相对共同框非直角旋转时强制锁定缩放比例；底层同时检查变换后两轴垂直，无法表示的斜切明确拒绝，保留上次有效预览。尺寸、位置或组蒙版预算超限整次拒绝，不逐层夹取尺寸。
- 多次拖动只更新预览，完成一次事务。取消、返回原框、原地完成不增加历史、不清空重做；保存、导出和 AI 使用已提交文稿。切文稿/工具/目标/选择、后台或源状态改变后旧输入不能提交。

## 上游依据

对照官方 Compositor `365b5745eda537f984f3d5bed1e53c361dbc9c91` 的 `Document/LayerTransform.swift`：复用 `TransformGroup` 的共同包围框与源几何、`following` 的精确平移和按共同框映射思想，以及已有 iPad `FreeTransformGesture` 的锚点/旋转手势。上游 `placing` 会丢弃非等比缩放产生的斜切；iPad 此处显式拒绝，不宣称任意仿射变换兼容。保留第三方 MIT 与来源声明。

## 验收入口

图层面板多选后点“共同变换”，或选中有内容的组后使用自由变换。检查隐藏/锁定、子树去重、组蒙版和剪贴随动；多次移动/缩放/旋转/翻转后完成，一步撤销/重做，保存重开继续编辑。再检查取消、原位完成、选区拒绝和旋转层比例锁定。自动化与真机安装记录见 [iPad 状态](IPAD_STATUS.md)，实现不等于真机体验验收。

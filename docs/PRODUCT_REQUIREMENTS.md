# iPad 绘图与图像编辑产品需求

需求同步日期：2026-10-21。

## 最终产品目标

开发一个原生 iPad 绘图与图像编辑软件，**以 Compositor-ZH 为优先移植与复用基础，逐步覆盖 Photoshop 大多数常用绘画、修图、合成和图层编辑功能**，适配 Apple Pencil 与触控操作。ComfyUI 是编辑器中的 AI 辅助模块，Windows 提供 AI 运算、任务保存和工程备份。

这是用户明确的长期产品方向。此前“画布 → 蒙版 → AI 生成 → 新图层”的闭环是第一阶段的技术验收，不能作为整个产品完成的标准。首期暂未实现的常用编辑能力仍在产品路线内。

“大多数常用功能”按下表分解为开发基线，不等于逐项复制 Photoshop 的所有菜单、桌面插件和专业工作流。下面列出的能力是规划目标，不代表当前代码或 Compositor 已实现；具体上游覆盖情况须通过源码和运行验证建立清单。

## 使用方式与分工

- iPad 是主要创作设备，提供完整的本地文档、画布、图层、工具和编辑历史。
- Windows 关机、网络断开或 ComfyUI 不可用时，iPad 仍可打开本地工程、绘画、编辑、撤销、保存和导出；受影响的仅是远端 AI 与备份功能。
- AI 操作使用当前画面、图层或选区创建任务；结果进入候选区，由用户应用为新图层或可撤销编辑。
- Mac 用于原生应用开发、构建、模拟器与 iPad 真机调试。Windows 首期继续负责桥接与 AI，无需同时开发完整 Windows 编辑器。
- Git 同步源码与需求；运行时画稿和任务通过局域网桥接传输。

## 规划功能基线

| 能力 | 常用功能目标 | 主要验收方式 |
| --- | --- | --- |
| 文档与画布 | 新建、打开、多文档、缩放、旋转视图、画布与图像尺寸调整、裁切、自动保存与异常恢复 | 实际工程保存重开一致；画布坐标在各种视图变换下稳定 |
| 绘画工具 | Pencil 笔压与倾斜、笔刷预设、大小/硬度/流量/不透明度、橡皮、吸色、填充与渐变 | 真机连续绘画、擦除与撤销可用，记录设备和画布条件 |
| 图层体系 | 新建/复制/重排/合并、图层组、锁定、透明度、常用混合模式、剪贴关系与图层蒙版 | 嵌套组、混合、蒙版与透明度在显示、保存和导出时一致 |
| 选区与蒙版 | 矩形/椭圆、套索/多边形套索、魔棒或相近颜色选区、选区加减交、反选、羽化与蒙版编辑 | 画笔、填充、调整及 AI 使用一致的选区语义，软边不被重复应用 |
| 几何编辑 | 移动、自由变换、缩放、旋转、翻转、透视与变形，后续液化 | 对图层和选区的坐标、插值、边界与撤销进行验证 |
| 色彩与调整 | 亮度/对比度、色阶、曲线、色相/饱和度、色彩平衡等常用调整；优先可再次编辑的调整层 | 调整顺序、影响范围和重新编辑结果一致，不强制压平原稿 |
| 修图与滤镜 | 仿制图章、修复工具，以及模糊、锐化、噪点等常用滤镜；渐进加入可编辑效果 | 多步修图不破坏原稿，预览和应用一致，操作可撤销 |
| 文字与形状 | 基础可编辑文字、字体与排版、基础形状和描边填充，后续路径编辑 | 保存重开后可编辑；缺字体或不支持效果时明确提示 |
| 文件与颜色 | PNG/JPEG 导入导出、可靠的分层工程保存；逐步支持 PSD 导入导出和更完整的色彩管理 | 按支持矩阵验证；禁止把压平导出称为分层 PSD 往返兼容 |
| AI 辅助 | 灵感变体、上色、光影材质、局部编辑、扩图、放大等逐步增加的预设 | 原稿保留、位置正确、候选可比较、结果可撤销、断网可恢复 |

笔刷格式兼容、完整 PSD 智能对象/效果往返、桌面插件与动作、CMYK/专色印刷、16/32 位和 HDR 等列为后续专项评估。它们不阻塞早期可用版本；若纳入具体发布版本，必须写明范围、测试样本和兼容限制。原生工程格式与 AI 接口格式应分别定义，当前 API v1 的 8 位 sRGB 限制不等于编辑器永久只支持这一种文档格式。

## AI 绘画扩展需求

Windows 侧继续扩展多模型与多工作流，iPad 按绘画用途选择兼容工作流和模型。用户明确需要线稿绘制与完善、线稿上色、灰稿二分明暗与四档明度、光照、场景绘制和人像精修；二分与四档明度同时区分精确明度归纳和 AI 重新设计明暗。

补充的场景、候选模型分工、Windows 与 Mac 协作边界及开发顺序见 [AI 绘画场景与多模型工作流规划](AI_PAINTING_WORKFLOWS.md)。材质、局部结构修正、角色一致性、素材提取、清除修补、扩图与放大纳入候选路线。模型文件存在不等于客户端已经支持；具体用途按输入、结果、性能和画稿质量分别验收。

基础编辑继续支持离线运行；AI 候选保留原稿并作为可撤销新图层加入。工作流选择和扩展不能破坏原配对、任务恢复、裁切坐标与透明度约定。

当前 AI 增量已实现 [PR #9 的 Windows 多预设 v0.2](https://github.com/yonakiluo-hub/compositor-ipad/pull/9) 与 [PR #10 的 iPad 固定预设选择](https://github.com/yonakiluo-hub/compositor-ipad/pull/10)。默认保留 Klein，Qwen-Image-2.1 与 Turbo 为默认关闭的实验组合；工程与合成样本 GPU 验证不代替绘画质量准入或新模型 iPad 真机联调。先评测现有组合的代表画稿效果，再按缺口决定 SDXL、结构控制和专用模型等后续候选；多参考、多候选、原生蒙版重绘、扩图与真正超分仍需独立实现。

## Compositor 复用要求

Mac agent 在扩展应用前，应建立 `docs/COMPOSITOR_PORT_MATRIX.md`，逐项记录：功能、上游文件与提交、实际支持情况、AppKit 依赖、iPad 改造方式、测试样本、移植状态。先保留和适配可复用的文档模型、渲染、图层、蒙版、工具算法、撤销事务与工程读写；针对触控、Pencil、菜单和面板重新设计 iPad 交互。

临时独立画布或 PencilKit 可以验证输入和通信，但必须说明替换或整合路径。阶段 1 验收前应接入可保存重开的文档、图层和撤销核心，不能让临时的压平位图或 PKDrawing 成为完整工程的唯一状态，也不能只参考上游界面、放弃核实可复用实现。保留引入源码的 LICENSE、NOTICE 和来源记录。

## 架构底线

- 文档核心、渲染与工具、平台输入、网络任务分离。绘画和普通编辑不等待远端网络。
- 使用稳定文档/图层 ID、统一坐标系和编辑事务。图层组、蒙版、可编辑调整等能力有明确的扩展方式；不必首版一次实现全部效果。
- 撤销重做覆盖工具、图层与 AI 插入；持久化工程与内存状态保持一致。旧任务返回不能覆盖后续编辑。
- 对大画布采用适合 iPad 的内存与渲染策略，评估分块、缓存和按需加载；在实际设备上记录性能，避免承诺未测试的画布大小或固定帧率。
- 对未知图层、效果和格式字段采取保留、明确拒绝编辑或经用户选择转换的策略；禁止静默丢失内容。
- 当前桥接的 4M 输入像素和 64 MiB 快照限制不定义最终编辑器的画布/工程上限。大工程、颜色精度与 PSD 互通按独立支持矩阵演进。
- AI 的生成区域、选区、透明度与文档色彩转换可追踪；当前模型预设仍为参考编辑后应用输出蒙版，不能宣称模型原生蒙版重绘已完成。

## 阶段路线与完成标准

| 阶段 | 交付重点 | 完成标准 |
| --- | --- | --- |
| 0 上游盘点与核心方案 | Compositor 功能/平台依赖清单、文档与渲染复用方案、原生 iPad target | 能构建，明确各项能力的复用或改造路线，保留上游来源 |
| 1 首个可运行闭环 | 基础图层、Pencil/蒙版、撤销、保存，以及 mock 和真实 Windows AI 接入 | iPad 能生成候选并回填新图层；分别记录模拟器、真机、网络验证 |
| 2 常用绘画与合成 | 笔刷、图层组、混合、剪贴、蒙版、常用选区、自由变换与本地恢复 | 断开 Windows 后仍能完成多图层绘画和合成，并保存重开 |
| 3 常用图像编辑 | 色阶/曲线等调整、修复/仿制、常用滤镜、文字形状、透视/变形及逐步液化 | 按功能清单验收可编辑性、撤销、选区作用域和保存一致性 |
| 4 日常使用版本 | 文件交换与 PSD 支持矩阵、性能与稳定性、工具完整度、AI 工作流体验 | 用户真实画稿工作流可连续完成；发布范围内的功能均有明确验证结果 |

这些阶段可以并行推进部分模块；阶段 1 完成后仍继续推进常用编辑能力。只有用户调整产品方向，才缩减长期范围。

## 当前实现状态

已实现 Windows 桥接，以及 `ipad_app/` 下的首版原生 iPad 编辑器：离线分层绘画、基础图层与选区、蒙版、变换、可撤销像素调整、分层保存和桥接客户端。具体实现、测试及仍未支持的内容见 [iPad 状态](IPAD_STATUS.md) 与 [上游移植清单](COMPOSITOR_PORT_MATRIX.md)。上表仍是完整规划，不能把基础版本写成全部功能已完成。

后续由 Mac agent 把每项功能标记为“未开始、实现中、模拟器验证、真机验证”并关联源码与验收记录。第一阶段完成只说明技术链路可用，最终交付仍按本需求中的绘画与图像编辑范围评估。

# 组蒙版

本轮范围：组可新建白色蒙版、由选区创建、直接绘制、填黑/填白、反相、停用/启用、移除及载入选区；嵌套、剪贴、预览、导出、合并、撤销和工程重开使用同一合成规则。整组携带蒙版的变换已在后续接入，见[共同变换](IPAD_MULTI_LAYER_TRANSFORM.md)；独立蒙版位置/未链接蒙版仍待后续。

## 合成规则

图层组仍为穿透组，组透明度沿用旧规则，逐层乘入后代。处理一个启用组蒙版时，先保留组下方画面 B，再按原有次序、混合、图层蒙版及剪贴规则得到加入组内容后的画面 A；最后在预乘 RGBA 中计算 B + M × (A − B)。M 是变换到文稿坐标的灰度组蒙版。组外像素不变，嵌套组由内向外处理。

所以白色精确保持原穿透外观，黑色恢复组下方画面，半灰覆盖只作用于整组结果一次。蒙版不会逐子层重复相乘；组的透明度仍逐后代乘入，并未改成隔离组透明度。组本身只接受正常/穿透混合，不支持剪贴到组或以组为剪贴基底。

新建组蒙版绑定创建时的文稿网格，组内各子层原 PNG 和变换不变。跨组整理携带该组的蒙版及绝对位置；单层移动不移动祖先蒙版。扩大画布时原组蒙版保留原网格并补白；图像缩放同步缩放蒙版几何。蒙版外的覆盖为黑色。

## 格式与上游边界

对照官方 Compositor `365b5745eda537f984f3d5bed1e53c361dbc9c91` 的 `Document/LayerMask.swift`：沿用数值灰度、变换放置与现有蒙版编辑机制。上游 `FolderMaskClip` 对每个后代施加祖先蒙版；本文的整组结果插值是 iPad 新增规则，二者在重叠半透明内容中并不等价。

资源仍使用标准 `maskFile`、`maskEnabled` 和组的 `transform`。含组蒙版时，绑定清单摘要的 `ipad-state.json` 额外保存 `groupMaskCompositing: "pass-through-result-v1"`。缺失或未知标记的组蒙版工程明确拒绝，避免把上游逐层蒙版静默解释成整组覆盖。无组蒙版的现有栅格工程兼容规则不变；上游重存可能移除 iPad 状态，不能承诺跨编辑器组蒙版外观往返。

组蒙版使用有界临时合成表面；超过预算的嵌套/尺寸组合在编辑验证时拒绝。当前 4096 单边、1600 万像素面的限制仍保留，预算不代表大画稿真机性能已经验收。

## 验证与真机步骤

完整 SwiftPM 177 项（3 项 HTTP 集成按环境跳过、0 失败），原生 99 项和 UI 13 项通过。新增核心 16 项、原生流程 6 项、UI 2 项。UI 初轮在宽工具栏外的手指开关处触发 XCTest 可点击性错误；调整夹具为先设输入模式再进入蒙版后，最终完整运行通过，保留绘制/撤销/启停/重开断言。截图已核对黑蒙版中的白色笔迹恢复与分层重开。

1. 离线打开带两个重叠图层的组，选中组并点“添加组蒙版”，白色应保持原外观。
2. 用黑色绘制隐藏整组，再用白色恢复；半灰软边应只覆盖一次。子层原像素、独立蒙版和剪贴仍可编辑。
3. 分别测试填黑、填白、反相、停用/启用与选区转蒙版；取消选区后再次绘制，确认不受旧选区限制。
4. 一次撤销/重做，保存并重开；再次点组蒙版缩略图继续编辑。试一组嵌套蒙版和组内剪贴。
5. 锁定组或祖先后应拒绝编辑；子层锁定仍保护其原像素，未锁定祖先的组蒙版可编辑。

模拟器与合成像素不能代替 Pencil 手感、大画稿持续性能和用户实际作品验收；安装状态另见 [iPad 状态](IPAD_STATUS.md)。

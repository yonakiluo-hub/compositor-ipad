# Compositor iPad 原生客户端

原生 iPadOS 17+ 绘画与图层编辑客户端，使用 SwiftUI、UIKit、Core Graphics 和 Core Image。普通编辑、分层保存和 PNG/JPEG 导出可离线使用；Windows 桥接负责可选的 AI 生成与工程版本备份。

这是首个可运行的编辑器基础版本，**尚未完成产品需求中的全部常用 Photoshop 工作流**。实现范围、验证证据和后续工作见 [iPad 状态](../docs/IPAD_STATUS.md)，完整目标见 [产品需求](../docs/PRODUCT_REQUIREMENTS.md)。

## 构建与测试

用安装了 iOS SDK 的 Xcode 打开 `CompositorPad.xcodeproj`，选择 `CompositorPad` scheme 和 iPad 模拟器。最低部署版本为 iPadOS 17；真机运行需要选择自己的 Development Team、有效签名以及已信任的 iPad。

从仓库根目录构建模拟器应用：

```sh
xcodebuild -project ipad_app/CompositorPad.xcodeproj \
  -target CompositorPad -configuration Debug -sdk iphonesimulator \
  SYMROOT=/tmp/compositor-ipad-build/Build/Products \
  OBJROOT=/tmp/compositor-ipad-build/Build/Intermediates.noindex \
  CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- build
```

运行可在 Mac 执行的文档、渲染和桥接测试：

```sh
cd ipad_app
swift test
```

iPad 笔刷与应用界面测试位于 `iOSTests/`，需要可启动的模拟器。脚本会选取已安装的 iPad，也可通过参数指定设备 UUID：

```sh
bash ipad_app/tools/verify_ipad.sh
# 或：bash ipad_app/tools/verify_ipad.sh <iPad-simulator-UUID>
```

工程文件已纳入版本控制。添加或删除源文件后，用 `python3 ipad_app/tools/generate_project.py` 更新工程，再编译。核心 Swift Package 名称为 `CompositorKit`；不依赖外部 Swift 包。模拟器使用本地 ad-hoc 签名以保留 Keychain entitlement；完全关闭签名的应用可能无法访问钥匙串。验证脚本使用 Xcode 支持的 `test-without-building`，也适用于 SDK 与已安装模拟器运行时版本不同、scheme 自动目标解析失败的环境。

每次脚本验证会在构建目录的 `TestResults/run.*/Tests.xcresult` 保留独立结果包，重跑不会覆盖上一次诊断。GitHub 原生测试失败时上传该目录为 `ipad-test-results-<run-id>-<attempt>`，保留 7 天；可下载后在 Xcode 中检查截图、界面层级和失败活动。CI 仅使用隔离模拟器及合成画稿。

## 使用

- 文件菜单可新建画稿、打开 `.comp`、导入图片为图层、保存与分享分层工程，或导出 PNG/JPEG。JPEG 导出使用白底。
- 默认 Pencil 绘画、手指平移；开启“手指绘画”后，单指绘画、双指平移缩放。双指轻点撤销，三指轻点重做。笔压与倾斜已接入；已由用户在真机确认基本 Pencil 绘画、撤销和重做，精确延迟、倾斜与防误触仍需专项验证。
- 图层面板支持显示隐藏、不透明度、锁定、复制、删除、同级排序、图层组和已实现的混合模式；可多选、合并符合条件的图层及创建隐藏的画布盖印副本。普通层、多选整层及整组均可移动、缩放、翻转和旋转。
- 选区笔、减选、矩形、椭圆、自由套索、多边形套索和反选形成同一覆盖蒙版；绘画、填充、调整和 AI 遵循选区，灰度软边不会重复应用。选区可转为链接图层蒙版；蒙版可直接绘制、填充、反相、载入为选区、启停和移除。
- 亮度、对比度、饱和度及高斯模糊应用到当前图层像素，保留蒙版并可撤销；曲线和色阶已使用可再次编辑的调整层，入口与边界见下文。
- 编辑后自动保存到应用的文稿目录；后台切换前尝试保存。保存失败会明确显示，切换文稿时会保留当前工作。

当前画布及每张可解码栅格资源限制为单边最多 4096 像素、总计最多 1600 万像素。此限制用于初版内存保护，不代表这些尺寸已通过长期真机性能验收。

扩大画布会同步扩展图层绘画范围，保留旧像素和蒙版的原始位置，新增区域透明、蒙版为白；整个操作可一次撤销。缩小画布不删除画布外像素。为避免边缘变淡或被蒙版遮住的内容显现，涉及非直角旋转、非整像素边界，或需要平滑/高质量插值的缩放及不同分辨率蒙版时，暂时明确拒绝无法保真的扩展；超过栅格资源上限也会整次回滚。图像大小的“同时缩放图层”仍保留原 PNG，仅调整几何。

## 图层蒙版、多选与合并

- **编辑蒙版**：选中普通图层，点“添加图层蒙版”建立全白蒙版，或从“蒙版 → 使用当前选区”创建。点蒙版缩略图或将“编辑对象”切到“蒙版”，即可用 Pencil 或手指绘画；选中的缩略图有边框，底栏显示当前目标。“返回图像”切回像素编辑。
- **黑色隐藏、白色恢复**：底栏选择黑白模式会切到画笔。橡皮在蒙版上始终表示隐藏；改选“白色显示”即可恢复。修改的是灰度蒙版，原图像素保留；大小、硬度、浓度及软选区限制继续生效。可填黑、填白或反相，也可从蒙版载入选区。停用蒙版时仍可编辑，其效果在启用后显示。
- **多选**：图层面板点“多选”，再点行或选择圆圈增减图层。选择集合属于导航，不增加文稿版本或撤销步骤；“完成”回到单层编辑。多选可用于合并、图层整理和共同变换，尚不支持多层同时绘画或调整。
- **整理图层**：图层面板顶部的“整理图层”按钮打开移动/成组/移出组面板。可把已有图层或整个子树批量放入任意组或画稿顶层，指定最上/最下或某个同级项目上方/下方。同父组内连续项目可成组，保留原同级位置；移出组会放在原父组上方，空组保留。组和其后代同时选择只处理一次，次序按画面自下而上确定。每次整理只占一步撤销，保存重开保留结构和原 PNG。
- **整理边界**：隐藏项目可移动，显示开关不变；所选子树、源祖先或目标祖先有锁定项目时拒绝。剪贴须完整选择基底及全部剪贴层；拆散所选或目标处的依赖均整次拒绝，不自动解除或改绑。跨父组会继承新上级的可见性/透明度并改变叠色上下文，画面可能改变；不烘焙像素或补偿透明度。跨组/不连续成组、解散组和拖拽整理暂未支持，规则及验收见[组整理说明](../docs/IPAD_GROUP_ORGANIZATION.md)。
- **合并**：多选后点“合并所选图层”；单层可“向下合并”，单个组可“合并组”。支持同一父组内连续的项目，组的后代计入且不重复。待合并内容须可见、未锁定，像素层须为正常混合，上级未选中的组不透明度须为 100%；不满足时界面说明原因。选择整个组可把组内透明度一起合入。
- **保留范围与撤销**：合并按当前显示比例固定所选图层的像素、蒙版、旋转和透明度，保留完整图层范围，包括画布外像素；最终单边不超过 4096、总计不超过 1600 万像素。不会按照选区裁切。新层保留同级位置，一次撤销恢复全部源层；8 位 PNG 合成会有量化误差，测试样例最大预乘 RGBA 差值不超过 2/255，不承诺原始字节或高分辨率采样无损。
- **盖印副本**：将当前可见画布合成为新层，原图层全部保留。副本默认隐藏，避免半透明内容在源图层上重复叠加；需要时手动显示或用于后续处理。盖印只包含画布内画面，不是画布外内容的备份；当前选区不限制盖印。

这些功能沿用现有 `.comp` 栅格层和灰度蒙版格式，保存重开继续保留内容。同组连续图层的剪贴蒙版和组蒙版已接入，规则见下文；曲线/色阶及可编辑调整层也已接入；未链接蒙版、蒙版独立变换仍待后续开发。本轮验证进度见 [iPad 状态](../docs/IPAD_STATUS.md)，尚不能沿用此前真机变换验收作为新图层工具的验收。

## 组蒙版

选中图层组，点“添加组蒙版”，或从“组蒙版 → 使用当前选区”创建。点组的蒙版缩略图可直接绘制；黑色隐藏、白色恢复整组，灰色对整组绘制结果覆盖一次。支持填黑/填白、反相、载入选区、启停和移除；原子层 PNG、蒙版及变换保持可编辑。组或其祖先锁定时不能编辑组蒙版；子层锁定保护子层内容，仍可编辑未锁定的祖先组蒙版。

组仍为穿透组，组透明度沿用逐后代乘入的旧规则；组蒙版在组内混合、独立蒙版与剪贴完成后，对加入整组前后的预乘画面插值。白色保持原外观，黑色恢复组下方画面，嵌套由内向外处理。此规则与上游逐子层 `FolderMaskClip` 不同，含组蒙版的工程必须保留 iPad 合成标记；缺失/未知标记的外来组蒙版工程会明确拒绝。详见[合成、格式和验收边界](../docs/IPAD_GROUP_MASKS.md)。

每笔和每次操作可一步撤销，保存/重开保留原资源与状态。扩大画布时原组蒙版补白，图像缩放改变其几何而保留原灰度样本；不能无损扩展的采样仍明确拒绝。嵌套组蒙版有临时表面内存预算，超过预算时整次拒绝；不代表最大画布已通过真机性能验收。组可通过下节共同变换携带蒙版，独立/未链接蒙版仍未支持。

## 多层与整组共同变换

多选后点“共同变换”，或选中有像素内容的组后点“变换图层组”／左侧自由变换工具。八手柄缩放、圆柄旋转、框内移动，底栏可水平/垂直翻转，再点“完成”。所有所选普通层与组内子层使用同一枢轴，选中组及其子层只携带一次；隐藏层包括在内，锁定项目或祖先会使整次变换拒绝。

组蒙版及普通层链接蒙版随动，原 PNG、灰度样本、层序、UUID 和剪贴引用保留。选择剪贴层或基底中的一部分可以改变相对位置，不会解除剪贴关系；未选中祖先的蒙版保持原位。有选区时，多层/整组入口要求先取消选区；只选一个普通层仍可使用原有选中内容变换。

含非直角旋转的源层或组蒙版时，比例开关保持锁定，防止产生当前格式无法表示的斜切；不会自动压平或丢弃斜切。预览不进入保存/导出，完成一次事务；取消、原位完成保留重做。下一次开始时重新计算直立共同框，框的旋转角不作为独立组参数持久化；子层各自的几何会保存。范围、来源和验收步骤见[共同变换说明](../docs/IPAD_MULTI_LAYER_TRANSFORM.md)。

## 曲线、色阶与可编辑调整层

顶栏“调整图层”菜单可新建曲线/色阶调整层。曲线支持 RGB 与红/绿/蓝独立控制点，点按添加、拖动调节、逐点选择、删除及输入/输出滑杆；色阶支持输入黑白场、gamma 和输出黑白场。选中已有调整层后可重新编辑参数；原图层 PNG 保持不变。

预览在后台串行更新，完成一次撤销事务；取消、恒等新建和仅切换通道保留重做。新建时当前软选区保存为调整层蒙版，重编不会重复叠加选区。调整作用于下方合成，组沿用穿透规则；创建剪贴蒙版可限制到单个栅格基底。支持现有蒙版绘画、启停、透明度、显隐、复制及层序调整。只有正常混合；包含调整层的集合暂不直接合并，可使用隐藏盖印副本。

保存重开保留参数、原图和数值蒙版。含调整层的工程要求 `ipad-state.json` 中保留 `pass-through-lut-v1` 标记及清单摘要；未知调整或外来语义明确拒绝。自动色阶、直方图、滴管及更多调整类型仍待后续。完整来源、作用域、文件边界和真机步骤见[调整层说明](../docs/IPAD_COLOR_ADJUSTMENTS.md)。

## 剪贴蒙版

在有轮廓或透明边缘的图层上方新建普通图层，选中它并点“创建剪贴蒙版”。上层的上色、纹理与调整只在基底的不透明区域显示，原始像素和本层灰度蒙版仍保留。可连续添加多个剪贴层；半透明底层的覆盖只应用一次，避免软边变厚。

- 剪贴关系固定到同组下方的基底层。移动、旋转或绘制基底及其蒙版会实时改变剪贴范围；移动上层只移动自己的内容。隐藏基底会隐藏整组剪贴内容，隐藏某个上层不会中断其他上层。
- “释放剪贴蒙版”会释放当前层及其上方同一基底的连续剪贴层，恢复显示原像素；创建与释放均可一步撤销。已有剪贴关系的基底须先释放其上层关系，才能再剪贴到更低的层。
- 复制剪贴层仍使用同一基底；复制图层组会重新映射组内关系。单独复制基底的副本位于原剪贴堆栈上方，避免拆开原关系。
- 删除基底、重排或跨组移动若会拆散关系，会明确拒绝并保留原稿。可先释放剪贴关系，或在“整理图层”完整选择基底及全部剪贴层一起移动/成组，也可操作包含完整关系的组。多选合并须包含基底及全部剪贴层；盖印仍保留所有源层。
- 关系保存到标准 `.comp` 的 `maskSourceID`（格式 v5 起支持）；本轮只接受同父组、连续、直接指向普通栅格基底的栅格层或曲线/色阶调整层。上游的跨组、链式或分离实时蒙版仍明确拒绝。iPad 隐藏基底会隐藏整个堆栈，这与上游任意实时蒙版允许隐藏源继续提供覆盖的行为不同，不能宣称此场景双端显示一致。

## 套索、组合与羽化

- **自由套索**：沿轮廓拖动，放手后自动闭合；轻触或共线轨迹不会创建选区。Pencil 可直接操作；使用手指前开启“手指绘画”。
- **多边形套索**：逐点轻触添加顶点，靠近首点轻触或点底栏“完成”闭合；“撤点”移除上一顶点，“取消”放弃当前路径。至少需要三个不共线点。平移和缩放保留已落下的顶点，坐标始终属于文稿。
- **新建、添加、减去、相交**：在底栏选择模式，适用于矩形、椭圆及两种套索。“添加”取较大覆盖、“减去”做饱和相减、“相交”取较小覆盖；这些是栅格灰度组合，避免重复添加同一软边时变得更实。减去和相交需要先有选区；明确的全黑选区表示全部保护，并不等于取消选区。
- **羽化**：底栏设置新形状的 0–100 像素羽化。已有选区可从“选区操作 → 羽化当前选区…”预览后应用；取消不改文稿。沿用上游高斯 sigma=半径/2 与画布边缘钳制约定，当前选区再次羽化会继续柔化已有边缘。
- **取消选区**：有选区时，画布下方直接显示“取消选区”按钮；点按后恢复整幅编辑，不删除图层或像素。可撤销恢复选区，取消后的状态也会随工程保存。“选区操作”菜单保留同一入口。
- 创建形状时固定当前模式、羽化参数和文稿版本；多边形尚未完成时参数控件锁定。切换工具、文稿或版本，以及退到后台，都会放弃未完成路径，保留已提交选区。每次完成选区或应用羽化各占一个撤销步骤。

最终覆盖保存为原有 `selection.png`，不改变工程格式或 Windows 接口。生成时裁切同一灰度蒙版，Windows 将它应用到候选 alpha；iPad 回填不会再次乘入。实际验收可用“多图层草稿 → 套索衣服 → 羽化 → AI 上色 → 加入图层 → 撤销 → 保存重开”。复杂画面效果及 Pencil 手感需在真实作品中继续验收。

按当前实际画布尺寸取得的真机合成处理时间、内存与后台保存测试见 [性能基线](../docs/IPAD_PERFORMANCE.md)；这些数值不等于 Pencil 到屏幕的延迟。

## 自由变换与画布旋转

- 选中有内容的普通图层，点左侧“自由变换”。手指或 Pencil 拖动八个边框手柄缩放，拖上方圆柄任意旋转，拖框内移动；锁定层和空层会明确提示，整组按共同变换规则处理。
- “锁定比例”默认开启，每次拖动开始时固定该选项。缩放固定对角或对边中点；越过对边时停在最小尺寸。已有翻转保持不变，翻转仍可从图层面板操作。
- 底栏显示宽、高和旋转角度。可连续调整，点“完成”一次提交，整个会话只需一步撤销；点“取消”放弃预览。切工具、图层、文稿、普通编辑或退到后台也会取消未完成变换。手势被双指导航打断时，只撤回正在拖动的那一步，保留之前的预览。
- 有选区时，变换框包围选区，移动、缩放和旋转当前图层选中的像素，灰度选区与羽化边缘一起随动；原位置按覆盖率移走内容，选区外像素保留。独立图层蒙版保持原文稿位置，必要时随图层扩边补白；不把蒙版烘焙到像素。没有选区时，变换整个图层及其链接蒙版，保留原 PNG。底栏会明确显示当前范围。
- 选区变换预览始终从冻结的原图生成，拖动中不反复重采样或编码；完成时将显示的像素和选区一起保存，一步撤销同时恢复二者。选区全黑或当前层选区内没有内容时会提示，不会改成变换整个图层。返回初始位置后直接保留原字节与重做记录。
- 向原像素边界外变换时，能直接扩边的图层继续使用原像素网格。旋转、非整像素位置或平滑缩放的图层会按当前文稿显示尺寸重新采样一次，再继续变换；底栏明确提示“完成将按当前显示尺寸固定本层的缩放与旋转”。保留完整图层范围（含画布外内容）、独立蒙版与禁用状态，不合并其他图层，不烘焙透明度或混合模式。取消、返回初始位置或撤销会恢复原始图层；完成后固定的分辨率会写入工程。只有实际像素尺寸/内存限制等失败会保留上个有效预览并报错。
- 整层/整组共同变换已接入；单层/选中像素透视及四角扭曲见[高级选区与几何](../docs/IPAD_ADVANCED_SELECTION.md)，多层选中像素仍未实现。预览期间保存、导出和 AI 使用已提交文稿，先点“完成”再使用这些操作。
- 双指可同时旋转、缩放和平移画布；画布下方“回正”恢复观看角度，“适合画布”同时回正并重新适配。视图角度不写入图层、选区或撤销历史。自由变换工具内手指直接操作手柄，双指导航；绘画工具的手指/Pencil 开关维持原语义。

验收建议：选择一个带蒙版的图层 → 锁比例缩小 → 圆柄旋转 → 移动 → 完成 → 撤销/重做 → 保存重开；再旋转画布，画一笔并确认位置。实际 Pencil 操作和双指手感需单独在真机确认。

## 连接 Windows 或 Mac 模拟服务

先按照 [桥接 README](../ipad_bridge/README.md) 启动现有服务。无需复制或重写后端。

1. 从服务提供方私下取得 `pairing.json`，传到 iPad 的“文件”中。
2. 在应用的“AI 工作台”选择“导入配对文件”，再选择“检查连接”。令牌保存到 Keychain；不要把配对文件提交到 Git。
3. 检查连接后，在“模型与生成组合”选择 Windows 提供的固定预设；等该项检查通过。旧服务继续提供原默认项，关闭或配置损坏的实验项不能选择。可选地绘制选区，填写生成描述，然后生成候选。无选区时发送全画布和全白蒙版；有选区时保留周围上下文，始终按原文档像素提交。
4. 预览候选后选择“加入新图层”。加入其他图层或继续绘画不会让旧候选失效：文稿版本变化时选择“使用旧版候选…”，确认后仍按生成时的位置加入独立新图层，保留现有图层。候选必须属于当前文稿，原画布尺寸和裁切位置仍有效；确认后又编辑则需重新确认。一次插入对应一次撤销。
5. 重新启动或恢复前台时会查询原任务。“重试未确认请求”复用已保存的请求 ID、metadata 和原 PNG；不会重新编码或换 ID 重发。
6. “备份当前分层工程到 Windows”上传不可变 `.comp` ZIP。首次上传前保留确切归档，后续同版本重试使用相同字节；切换配对或服务地址后，明确向当前配对服务上传这份原始归档，兼容旧缓存。当前界面尚未提供服务器备份下载与恢复浏览器。

模拟后端会明确显示“模拟服务 · 不执行 AI”；真实服务不会失败后自动切换到模拟模式。当前真实预设执行**参考图编辑，再把输出蒙版乘入 alpha**，不是模型去噪阶段的原生蒙版修补。客户端直接按返回坐标合成透明候选，不会重复应用同一输出蒙版。

新预设接入范围与双端验证见 [多模型客户端交接](../docs/IPAD_PRESETS_V02.md)。服务目录决定可见项；客户端不下载模型、不替 Windows 开启实验预设。结构检查、实际生成测试和绘画质量分别显示，检查通过不代表效果已经验收。生成区域采用全局与所选预设中更严格的限制，增加上下文时不缩放原画。已发送任务及其候选继续标识实际使用的组合，切换选择不改变旧任务。

## 候选管理

“AI 工作台”按次列出生成记录。最新成功候选自动预览，较早候选点按加载；预览缓存有数量和字节上限。一次生成目前通常包含一个结果，删除操作清理整次生成的候选，不是删除某个已加入文稿的图层。

- **仅从本机移除**：清理本机输入、蒙版和预览缓存，刷新或重开后继续隐藏；Windows 文件仍保留，不会释放 Windows 空间。可重新显示本机已移除的候选，再从服务按需下载；重新显示只取回已有结果，不会重新启动 AI 生成。
- **删除本机及 Windows 候选**：需要 Windows 更新到支持 `jobDeletionSupported` 的桥接版本，且任务已经成功或失败。确认后删除桥接保存的输入、蒙版、工作流和结果；排队或生成中的任务不能删除，此操作不取消生成。
- **删除中断或失败**：应用持久保存已确认的待删除任务，重开后仍可重试。只有收到匹配的删除成功回执才完成本机清理；服务返回 503 或连接中断不会被显示成清理成功。任务查询返回“已删除”也不代表文件清理已经完成。

以上操作都保留已经回填到文稿中的图层、撤销记录和工程备份。远端删除后的候选文件不能重新显示或找回。ComfyUI 自己的 input/output 文件不在桥接清理范围内，需要单独管理；因此不能将候选删除等同于释放所有生成占用。Windows 升级注意事项见 [桥接 README](../ipad_bridge/README.md#升级候选删除能力)。

## 分层工程格式

保存采用 Compositor v14 的 `manifest.json` 与 `images/` 目录包，保留每层原 PNG、变换、UUID、显示状态、不透明度、混合模式、穿透图层组、链接式灰度蒙版及受支持的曲线/色阶调整参数。新建空白层没有 PNG，开始绘画或扩展绘画范围时分配像素。保存完整包后原子替换旧文件。导入外部工程时若本机已有同一文档标识，会以新标识和版本 0 打开副本，保留本机已有版本；PNG/JPEG 导出只是独立的平面副本。

已用上游原始读取器和保存器完成一个分层、蒙版、变换及空白层样例的双向往返校验；它证明这个栅格子集可互通，不代表上游全部功能都已移植。

`ipad-state.json` 保存 iPad 的文稿名称、单调递增 Int64 版本、锁定状态、AI 插入收据及全画布选区引用。它绑定清单的 SHA-256；不一致时拒绝载入。`selection.png` 是该选区的无 alpha 灰度 PNG。这些额外文件不修改上游标准清单；上游重新保存时可能移除 iPad 专属状态。对未带此状态的上游工程，iPad 为导入会话建立新的版本基线。

导入只接受目前确实能编辑并保真的子集。含未知字段、文本、形状元数据、效果、未支持的调整类型、缺失/不兼容状态标记的调整层、辅助线、不支持的实时蒙版关系、未链接蒙版、缺失或不兼容合成标记的组蒙版、未实现的混合模式、16 位图像或 EXR 的工程会明确拒绝，不会悄悄栅格化或丢掉内容。资源路径、循环组结构、符号链接、大小和 PNG 类型也会检查。

工程 ZIP 使用无需额外依赖的 Stored 格式、CRC32、固定时间戳和确定的文件顺序；最大 64 MiB、最多 2000 项，同时服从服务能力。备份成功只表示归档及引用已通过桥接校验，不代表所有编辑器或功能都兼容。
